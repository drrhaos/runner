# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| latest release on `master` | yes |
| older tags | best effort |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report security issues privately by opening a [GitHub Security Advisory](https://github.com/drrhaos/runner/security/advisories/new) or contacting the maintainers through GitHub.

Include:

- A description of the issue
- Steps to reproduce
- Impact assessment
- Possible fix, if you have one

We aim to acknowledge reports within 7 days.

## Scope

This policy covers the Runner Android application and this repository. Third-party services (OpenStreetMap tile servers, Google Play Services Location) are governed by their own policies.
